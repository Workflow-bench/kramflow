Kramflow · Phase 3 · Design System (Redo)

A different console, not a re-tinted one

The first pass reused the incumbent system's exact palette, radii, and motion values under new citations — that's the theme-swap failure the brief warned against. This is an actual second pass: a different chrome temperature, a different accent hue and weight, sharper radii, a different mono face, different motion timing, and a queue-row state language that doesn't rely on a colored edge stripe.

What's structurally the same, and why that's not a copy

Two ideas survive from Phase 1/2's own reasoning, not from either prior file: achromatic chrome with hue reserved for meaning (P1.11 — color must carry one legible meaning) and a two-scale system split by posture (P2 §4). Keeping a sound structural principle while changing every executed value is design; keeping the executed values is not — that distinction is the actual fix here.

Chrome — warm graphite, not cool slate

A live-event control room runs warm-black hardware under practical stage light, not a cool-blue screen glow — this ramp sits at a warm-neutral hue (~30°) instead of the cool-slate (~220°) territory dashboards default to.

Type — Inter + IBM Plex Mono, two scales

Inter for language (handles Gujarati/Sanskrit diacritics correctly — a real content constraint, not a style pick). IBM Plex Mono, not the more common JetBrains Mono, reserved for tabular time/duration only — a face with more mechanical, less "developer-tool" character.

Guardrail-tiered danger buttons — P2 §5

Severity escalates through visual commitment on one hue (alert red), not through a spreading family of danger colors — tier 1 is text-only (link revoke), tier 3 is solid (session delete), tier 4 is solid-and-disabled-until-typed (event delete only).

Queue row — state without an edge stripe

The incumbent (and my rejected first pass) used a 2px colored left border to carry row state — a category default worth refusing on its own terms, not just because of where it came from. State here is carried by background wash and, for selection, a small leading dot — never a border rule.
